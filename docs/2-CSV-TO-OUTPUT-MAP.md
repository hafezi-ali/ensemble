# Which CSV drives which output

Generated by tracing an actual build, not written by hand — every row below was
recorded by instrumenting `make_figures.py` and reading the spec blocks in
`make_tables.py`.

```
results/*.csv  ->  make_results.py  ->  tables/*.tex + figures_out/*.pdf
                                              |
                                    document.tex \input's them
```

## Not generated from CSVs

Three assets are hand-drawn and deliberately outside this pipeline:
`fig1_pipeline` (built by `make_fig1.py`), `training_phase_diagram` and
`generalization_phase_diagram` (vector assets in `manuscript/`).

## How the PDF picks up regenerated figures

The build writes to `figures_out/`; the published originals in `manuscript/`
are left untouched. `document.tex` carries
`\graphicspath{{../figures_out/}{./}}`, which prefers a regenerated figure
once it exists and falls back to the published one otherwise. So the two
figures whose sweep data was never archived still render from their original
exports until you fill their CSVs.
